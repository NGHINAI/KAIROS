## 1. Definition of done for the whole migration

Production-ready means ALL of the following hold simultaneously:

- [ ] **Every current capability preserved.** Every item in §3 (Regression checklist) passes its guarding test on `KAIROS_BRAIN!=codex` AND on `KAIROS_BRAIN=codex` (where the lane is flipped). - [ ] **Codex brain on deep + background.** `[[think]]` deep turns and the background sub-agent / proactive-WORK lanes run on Codex (warm `codex app-server` for deep; `codex exec --json` for background) behind `KAIROS_BRAIN=codex`. **Smart VOICE stays on our loop by default** (LANE DECISION 2026-06-12); the smart-voice→Codex escalation hook exists but is A/B-gated, default off.
- [ ] **The ONE non-negotiable: verifier gates ported.** The full deterministic verifier gate stack (promissory / fabrication / do-mode / false-blindness / false-done / walkthrough / screen-offload + LLM groundedness + errored-write fast path) runs POST-turn over the translated Codex ledger, with MCP namespace stripped, one-corrective-turn re-injection on `retryable`, `self_correct` emitted, and StreamSpeechController block-writes re-implemented on the Codex delta path. **Never ship the swap without this.**
- [ ] **Clicky guidance shipped.** Region/block highlight, scroll guidance, arrow affordance, bullseye+pill — in KAIROS warm-gold→cyan liquid glass (NOT Clicky red), AX-resolved (unionFrame + scrollableAncestor), default-`point` path byte-identical. Notch state surface + Agents surface + original sounds + secure/capture auto-hide + buddy behaviors.
- [ ] **Hidden inference proxy.** One portable `export default { fetch }` handler (Bun.serve localhost in dev, Cloudflare Worker on ship — only `base_url` differs). Responses-API inbound, OpenRouter chat/completions outbound, dedicated `KAIROS_BRAIN_KEY` server-side only, alias map (`kairos-smart`/`kairos-deep` → real slug, never leaked), per-install token auth, facade-side metering + hard budget enforcement + kill-switch. Real OR slug appears in **no** bundle/config/traffic/log.
- [ ] **Everything behind flags.** `KAIROS_BRAIN=codex|local` switches deep+background lanes only (fast chain + smart-voice never gated by it). Flag is documented TEMPORARY; removed once stable. `KAIROS_HIDE_ON_CAPTURE`, `KAIROS_CODEX_WEB`, notch opt-in all default to the documented lean.
- [ ] **Composio invisible to Codex.** Codex only ever calls `search_tools`/`execute_tool`; OAuth/connect/self-heal/token-refresh stay 100% daemon-side. Auto-connect inline on `NOT_CONNECTED` envelope (not throw) works through Codex within one turn.
- [ ] **Self-learning keeps feeding.** Codex turns translate to one `TrajWriter.record()` per turn (namespace-stripped, `execute_tool` unwrapped); AwmWorker clusters Codex turns against in-house-loop turns; crystallized skills surface back as MCP tools.
- [ ] **Memory parity.** Durable persona/doctrine → CODEX_HOME instructions (re-written every regen, daemon is source of truth); volatile per-turn delta → `turn/start` instructions via `contextBuilder.build()` (self-echo hygiene intact); `recall_memory` exposed as MCP tool; KAIROS-authoritative conversation replay (no Codex double-history).
- [ ] **Ship-hardened.** Warm-child + MCP-server teardown / orphan reaping; codesign + notarize vendored codex/rg; isolated CODEX_HOME never touches `~/.codex`; unattended security posture enforced at the MCP layer.
- [ ] **No `claude -p` in the proactive path.** Proactive WORK re-routed onto Codex (it 401s in shipped builds — Anthropic is off the cloud path).
- [ ] All five **Blocked-on-Nirmal** decisions (§5) are recorded in doc 07; the deferred ones (Apple Dev ID) don't block dev but DO block final ship.
